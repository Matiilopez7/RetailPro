# RetailPro
Repositorio con las prácticas y entregas del curso de Data Analytics.

Tecnología
- SQL Server
- SQL Server Management Studio (SSMS)

Ejecución
Los scripts trabajan sobre la base de datos Ventas_Tech_DB.

1. Ejecutar primero el script del Módulo 3 para crear y cargar la base.
2. Abrir el archivo .sql del módulo correspondiente en SSMS.
3. Seleccionar Ventas_Tech_DB y ejecutar el script.
